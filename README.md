# 🎮 SA-MP Launcher (в браузере)

Браузерный лаунчер для SA-MP сервера **188.127.241.74:1198**. Сайт размещён на GitHub Pages, а обновляет его **GitHub Actions**.

**🌐 Открыть лаунчер:** https://pashawilliams.github.io/samp-launcher/

## Возможности
- 🟢 Статус сервера: онлайн/офлайн, название, режим, язык, версия, пинг
- 👥 Онлайн с прогресс-баром и список игроков с поиском
- 📈 График онлайна за 24 часа
- ▶️ Кнопка **«ИГРАТЬ»**: открывает клиент SA-MP по ссылке `samp://ip:port`
- 📝 Ник сохраняется в браузере
- ⚡ **Быстрый вход (.bat)**: записывает ник в клиент SA-MP и подключает к серверу
- 📱 Адаптивный дизайн

## Как работает
Браузер не умеет отправлять UDP-пакеты, поэтому сервер опрашивает workflow `.github/workflows/launcher.yml`:
1. Запускается при push, по расписанию (каждые ~5–15 минут) и вручную (**Actions → Run workflow**).
2. `scripts/query.py` опрашивает сервер по протоколу SA-MP query и сохраняет `data/status.json` и `data/history.json`.
3. Сайт из папки `site/` публикуется на GitHub Pages.

## Как добавить или сменить сервер
Отредактируйте `site/servers.json`:
```json
{ "id": "main", "name": "Мой сервер", "ip": "1.2.3.4", "port": 7777 }
```
Если серверов несколько, на сайте появятся вкладки.

> ⚠️ GitHub отключает запуск по расписанию в публичных репозиториях, если в них 60 дней не было коммитов. Включить обратно можно во вкладке Actions.
