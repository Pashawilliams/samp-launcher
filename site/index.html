Как начать играть

  1. Установите GTA: San Andreas (версия для ПК 1.0 US/EU).
  2. Установите клиент SA-MP 0.3.7: скачать с официального сайта. Он регистрирует ссылки samp://.
  3. Введите ник выше и нажмите «ИГРАТЬ». Если ник в клиенте не сменился, скачайте «Быстрый вход (.bat)» и запустите его.
Статус обновляется автоматически через GitHub Actions примерно каждые 5–15 минут · пинг измеряется с серверов GitHub
